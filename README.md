## 二、面板和 VPS 的真实差别：一个容器，一台完整系统

面板类跑在容器里，系统环境是雨云准备好的。你不用装 Java、不用配目录、不用写启动脚本，点「开启实例」等控制台出现 `Done` 就能联机；mod、插件、存档通过面板的文件管理或 SFTP 上传。代价是它只能用雨云提供的镜像，一个实例基本对应一个服务端。

VPS 是一台完整系统。要走 Windows 远程桌面还是 Linux 都行，服务端可以多开，也能顺便挂个网站、机器人、语音服务。但它不会帮你做任何事——Java 环境、`eula.txt`、启动参数、防火墙，全是你自己的活。

一个容易被忽略的细节：面板服支持按天计费，当天不开机不产生费用，数据保留 30 天。对「只有周末晚上一起玩」的固定小队，这个模式比包月划算得多。

## 四、机型比档位更影响体验：MC 吃的是单核

同一档配置，选不同 CPU 价格差一截。原因在于 Minecraft 服务端主要吃单核性能，核心多但主频低，人多的时候 TPS 照样往下掉。

雨云游戏云目前可选的高主频机型包括 Ryzen 9950X、Ryzen 7950X、Ryzen 5900X、i9 14900K/14900KF/14900KS、i9 13900K/KF、EPYC 7A23、Gold 6146、E5 2666v3、Platinum 8259CL/8275CL，以及较新的 W9-3495X。按单核性能大致排一下：

- **i9 14900K 系列 / Ryzen 9950X**：单核最强的一档。官方论坛的测评里，14900K 的 CPU-Z 单核跑分 738.7，属于目前能买到的第一梯队。适合 1.20+ 模组服、大型整合包、基岩互通。
- **W9-3495X、Ryzen 7950X**：单核跑分 620–700 左右，价格比 14900K 低，是「模组服但预算没那么宽」的常用选择。
- **EPYC 7A23 / Ryzen 5900X**：单核 460–520 区间。7A23 是 Zen3 架构，价格比 5900X 低，性价比不错，1.18+ 中小型 mod 服够用。
- **Gold 6146**：主频 4.2GHz。中低版本纯净服和插件服的主力，价格温和。
- **E5 2666v3 / Platinum 8259CL**：单核最弱的一档，但多核便宜。适合低版本小服、挂机服、朋友间随便玩玩，别拿来开高版本模组服。

## 五、固定计费和动态计费，怎么选不亏

雨云游戏云有两种计费方式，这是它区别于大部分云厂商的地方。

**固定计费**就是传统的按月包租，价格固定，随便跑。

**动态计费**是低基础月租 + CPU 超额日结。基础租金压得很低，实际用超了才按天补「电费」，闲置的时候几乎不花钱。注意只有 CPU 产生这项费用，内存、硬盘、带宽不算在内。

判断标准很简单：**每天实际开服超过两小时，固定计费更省心；低于两小时，动态计费明显更划算。** 只在周末开服、或者还在试玩法阶段的，先用动态计费跑几天，成本比你想的低。

但它有两个硬性限制，开服前必须知道：

1. **联机端口固定为 36895**，容器防火墙只放行这一个端口，改配置文件也没用，重启后会复原。玩家进服的地址格式是「公网 IP:36895」，少一个都不行。
2. **内存上限由系统锁定**，不能在启动参数里自己填 `-Xmx`。填了大概率直接启动失败、自动关闭。

免费机库存有限，售罄是常态，官方会不定期补货。用来练手、跑轻量生存服完全够，但别指望它扛大型模组包。

## 八、新手开服最容易踩的三个坑

**坑一：把 NAT 机型当成独立 IP 用。** NAT 机型共用公网 IP，必须先在后台配好端口映射，内部端口填 25565（Java）或 19132（基岩），协议对应 TCP 或 UDP，然后让玩家用「公网 IP:外部端口」连接。直接给朋友一个裸 IP，是连不上的。

**坑二：手动写了内存参数。** 面板类产品尤其明显。容器已经分走了一部分内存，你再把 `-Xmx` 写死，服务端经常起不来或者刚开就崩。用默认启动方式，让面板自己分配。

**坑三：视距和 mod 数量超标。** TPS 掉下来不是机器坏了，是配置超了。先把视距降到 5–6，再考虑加内存。

启动后判断是否开服成功，看控制台有没有出现 `Done`。`list` 可以查在线玩家，`stop` 是正常关服（会自动保存地图），别直接拔电源。
